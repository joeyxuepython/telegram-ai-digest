# Code of Conduct

We want participation in this project to be respectful, constructive, and safe.
Be considerate in issues, pull requests, discussions, and other project spaces.
Harassment, discriminatory language, personal attacks, doxxing, and sharing
private chat content without permission are not acceptable.

Report concerning behavior privately to the repository owner through GitHub.
Maintainers may remove content or restrict participation when needed to protect
the community.
